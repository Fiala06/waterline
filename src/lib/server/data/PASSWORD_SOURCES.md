# Common passwords

`common-passwords.json` is the 12-character-and-longer entries of
`Passwords/Common-Credentials/xato-net-10-million-passwords-100000.txt` from
[SecLists](https://github.com/danielmiessler/SecLists) (MIT License,
Copyright (c) 2018 Daniel Miessler), lower-cased and de-duplicated. The local
admin password is checked against it on the server (#102); nothing is sent
anywhere.
